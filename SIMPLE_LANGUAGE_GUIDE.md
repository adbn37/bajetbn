# BajetBN simple-language guide

BajetBN is written for people with little or no accounting knowledge.

## Rules

- Use short, everyday words.
- Explain what will happen before the user presses a button.
- Use action words on buttons.
- Do not show developer or accounting terms when a normal phrase works.
- Keep technical names in code and developer documents only.

## Preferred wording

| Avoid | Use |
|---|---|
| Transaction | Money activity |
| Posted | Saved |
| Ledger | Account activity |
| Outstanding | Left to pay |
| Commitment | Bill or instalment |
| Settlement | Payment |
| Finalise | Finish |
| Reversal / Reverse | Undo |
| Payment claim | Payment submitted |
| Allocation | Savings progress |
| Payee | Person or shop paid |
| Legacy | Old |
| Revoke invitation | Cancel invite |
| Insufficient permissions | You do not have access |

## Button examples

- Add income or expense
- Save payment
- Confirm payment
- Undo payment
- Finish old payment
- Add bill or instalment
- Give bill share

## Report wording

- Net cash flow → Money left
- Variance → More or less than the previous month
- Expense breakdown → Where your money went
- Financial health → Simple money check
- Amount payable → Still to pay
