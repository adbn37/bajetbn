# BajetBN v0.11.18 Signup Theme Onboarding

## Included

- Theme chooser remains on Login.
- Theme chooser is removed from registration.
- Signup shows an English or Malay financial accountability reminder.
- Onboarding contains a second theme-preview step.
- The current or guest-selected theme is preselected.
- Customers may save the selected theme or skip.
- Settings guidance is shown before continuing.
- Existing completed users are not sent through onboarding again.

## Staging gate

The feature remains manual_test until email and Google signup, theme save, skip, reload, mobile and language tests pass.
