# BajetBN v0.11.12 — Premium Theme Refresh Hotfix

## Purpose

This hotfix refreshes both BajetBN appearances without changing financial behaviour.

## Dark appearance

- Uses a near-black and charcoal foundation inspired by the approved ADBN TECH dashboard direction.
- Uses cyan-teal only for active navigation, primary actions, focus states, links, icons and chart emphasis.
- Keeps cards dark and neutral instead of outlining every panel in teal.
- Uses white primary text and calm grey supporting text.
- Keeps warning, overdue and negative states separate from the main accent colour.

## Light appearance

- Replaces the full-page mint wash with warm ivory.
- Uses white cards with subtle neutral borders and shadows.
- Removes dark navy blocks that remained inside light pages, including transaction filters, category cards, calendar items, search icons and offline details.
- Uses teal as a controlled accent rather than the page identity.
- Uses soft coral, amber and green only for meaningful status states.

## Boundaries

- No Firebase Functions, Firestore rules, Storage rules or indexes are changed.
- No financial calculations, transactions, reminders or offline behaviour are changed.
- Dark, light and device-default appearance choices remain available.
- The black appearance remains the default.
